Installation guide · step by step

Claw Phish V2 runs on Linux (Debian/Ubuntu, RHEL) & macOS · see docs/requirements

1 Clone the repository git
git clone https://github.com/Iankulani/claw_phish_v2.git cd claw_phish_v2
Repository includes: core/ modules/ campaigns/ reports/
2 Set up Python environment 3.10+
python3 -m venv claw-env source claw-env/bin/activate pip install --upgrade pip pip install -r requirements.txt
deps: flask, requests, beautifulsoup4, nmap, scrapy, etc. optional: --extra-index for GPU modules
3 Configure database & environment PostgreSQL / SQLite
cp .env.example .env # edit .env: set DB_URI, SECRET_KEY, SMTP settings python manage.py db upgrade
Generate secret: python -c "import secrets; print(secrets.token_urlsafe(32))"
4 Initialize modules & assets campaign templates
python clawctl.py init --all # or: python clawctl.py init --modules web,network,phishing,drills
phishing templates: assets/templates/ wordlists: assets/wordlists/
5 Run Claw Phish V2 production
python clawctl.py run --host 0.0.0.0 --port 5000 # or with gunicorn: gunicorn -w 4 'clawphish:create_app()'
access UI: http://localhost:5000 · default admin: admin@claw.local / ChangeMe123!
6 Post‑install: first campaign & drills ready

· Validate installation: python clawctl.py health

· Create a phishing campaign: python clawctl.py campaign create --name "Q2 awareness"

· Launch network scan: python clawctl.py scan --target 192.168.1.0/24

· Invite team members via settings → users
